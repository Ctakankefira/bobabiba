# Telegram Mini App - Маркетплейс Мастеров
## Полная документация проекта

### 📋 Обзор проекта
Платформа для мастеров услуг, где клиенты могут записываться онлайн через Telegram Mini App.

**Технологии:**
- Backend: NestJS + Prisma + PostgreSQL
- Frontend: Next.js + Telegram WebApp SDK
- Bot: Node.js + Telegraf
- Деплой: Railway (backend/bot) + Vercel (frontend)

## 🗄️ Структура базы данных (Prisma Schema)

### Модели:

#### User
- id: String (PK)
- telegramId: String (unique)
- role: CLIENT | MASTER
- createdAt: DateTime
- updatedAt: DateTime

#### Master
- id: String (PK)
- userId: String (FK to User)
- name: String
- description: String?
- category: String
- priceMin: Float?
- priceMax: Float?
- rating: Float (default 0)
- createdAt: DateTime
- updatedAt: DateTime

#### Service
- id: String (PK)
- masterId: String (FK)
- name: String
- description: String?
- price: Float
- duration: Int (minutes)
- createdAt: DateTime

#### Booking
- id: String (PK)
- clientId: String (FK)
- masterId: String (FK)
- serviceId: String (FK)
- date: DateTime
- status: PENDING | CONFIRMED | CANCELLED | COMPLETED
- notes: String?
- createdAt: DateTime
- updatedAt: DateTime

#### Review
- id: String (PK)
- bookingId: String (FK, unique)
- clientId: String (FK)
- masterId: String (FK)
- rating: Int (1-5)
- comment: String?
- createdAt: DateTime

#### Photo
- id: String (PK)
- masterId: String (FK)
- url: String
- alt: String?
- createdAt: DateTime

#### Favorite
- id: String (PK)
- clientId: String (FK)
- masterId: String (FK)
- createdAt: DateTime
- unique: (clientId, masterId)

#### Message
- id: String (PK)
- senderId: String (FK)
- sender: User @relation("sentMessages")
- receiverId: String (FK)
- receiver: User @relation("receivedMessages")
- message: String
- createdAt: DateTime

## 🔗 API Эндпоинты

### Аутентификация
- POST /auth/telegram - авторизация через initData

### Пользователи
- GET /users/profile - профиль пользователя (JWT required)

### Мастера
- GET /masters - список мастеров (фильтры: category, priceMin, priceMax, rating)
- GET /masters/:id - детальная информация о мастере
- POST /masters - создание профиля мастера (JWT required)
- PUT /masters/:id - обновление профиля

### Услуги
- GET /masters/:id/services - услуги мастера

### Записи
- GET /bookings - мои записи (JWT required)
- POST /bookings - создать запись (JWT required)
- PUT /bookings/:id/status - изменить статус

### Отзывы
- GET /masters/:id/reviews - отзывы мастера
- POST /reviews - оставить отзыв

### Избранное
- GET /favorites - избранные мастера
- POST /favorites - добавить в избранное
- DELETE /favorites/:id - удалить из избранного

## 🔧 Troubleshooting

### Backend крашится
- Проверить DATABASE_URL
- Запустить `npx prisma generate`
- Проверить JWT_SECRET

### Frontend не загружается
- Проверить BACKEND_URL
- Проверить CORS в backend

### Bot не отвечает
- Проверить BOT_TOKEN
- Проверить логи Railway
